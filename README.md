# Delivery Cost and Failed Delivery Analysis

## Project Overview
This is a self-initiated data analysis project created to analyse delivery performance, failed deliveries, and delivery costs using Python and Excel. The project aims to identify operational trends and evaluate the financial impact of failed deliveries.

## Objectives
- Identify delivery providers with the highest number of failed deliveries
- Analyse delivery costs across providers
- Generate KPIs to evaluate operational performance
- Visualise delivery trends and performance metrics

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset
This project uses a publicly available dataset for learning and portfolio purposes.

## Analysis Performed
- Data cleaning and validation
- Aggregation of failed deliveries by provider
- Delivery cost analysis
- KPI generation
- Data visualisation using bar charts

## Key Insights
- Identified providers with the highest failed delivery rates
- Measured the cost impact of failed deliveries
- Analysed operational performance trends through KPIs
